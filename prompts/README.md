# PromptMeUp prompt library

Reusable prompts for agents working on PromptMeUp.

| Prompt | Use |
| --- | --- |
| `01-choose-markdown-artifact.prompt.md` | Decide which Markdown file belongs to a task |
| `02-inventory-machine.prompt.md` | Inspect and document installed tools safely |
| `03-create-agent-rules.prompt.md` | Create scoped `AGENTS.md` and Copilot instructions |
| `04-write-architecture-decision.prompt.md` | Record a technical decision with evidence |
| `05-create-powershell-helper.prompt.md` | Create a safe reusable PowerShell script |
| `06-review-task-ledger.prompt.md` | Keep TODO, lessons, and archive aligned |
| `07-sanitize-repository.prompt.md` | Scan and remediate secrets, privacy, provenance, and Git history before publication |

Use each prompt by replacing the `{{PLACEHOLDERS}}`. Never paste secrets into a prompt.

# PromptMeUp support

Whether `hm` is not launching, setup is unclear, or a terminal workflow needs explanation, start in
[GitHub Discussions](https://github.com/umbertotechnopreneur/PromptMeUp/discussions). Search existing
discussions and issues first, and never post API keys, tokens, prompt history, unredacted command output,
personal data, or private machine paths.

Use the issue forms for reproducible bugs and focused feature requests. For a security vulnerability, follow
the private reporting process in [SECURITY.md](SECURITY.md); do not open a public issue or discussion.

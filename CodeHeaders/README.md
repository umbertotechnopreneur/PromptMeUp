# Code header templates

Reusable source-file headers for projects authored or maintained by Umberto
Giacobbi.

Start with [CodeHeaderTemplates.md](CodeHeaderTemplates.md). It contains the
complete catalog, placeholder rules, and copy-ready versions of every header.
The `templates/` directory contains the same headers as individual files.

## Use

1. Copy the template that matches the source language.
2. Replace every `{{PLACEHOLDER}}`.
3. For a private repository, remove the complete `Repository:` line.
4. Select a license that matches the repository's root license file.
5. Run a placeholder search before publishing.

Do not use `All rights reserved` together with an open-source license unless
that wording has received legal review. A source header identifies the
applicable license; it does not replace the repository's complete license text.
